About this GitHub Pages version. This is a client-side research workspace, not the complete Python backend. Keyword search, extractive summaries, comparison, and exports work in-browser. Semantic search can load a compact embedding model from a public CDN and may fail on restricted networks; it is optional. Scanned PDFs need OCR, which is included as an optional Google Colab workflow. For transformer QA, reranking, and heavier analysis, use the Advanced Colab notebook or deploy app.py with Streamlit Community Cloud.
