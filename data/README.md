# Data folder

Do not commit large collections of research PDFs or documents you do not have permission to redistribute.

For this app, upload PDFs through the Streamlit interface. The app processes the file bytes in the current session and does not write uploaded PDFs into this directory.

If you add research metadata later, document:
- the original source URL;
- download/access date;
- license or terms of use;
- fields and any cleaning steps;
- known sampling limitations.
